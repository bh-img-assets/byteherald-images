<p>DeepSeek said on Sunday, November 8, 2026, that Harness, its open-source agent application, reached 1.54 million daily active users by November 4, less than three months after its August 13 debut. The number counts only people using Harness through DeepSeek's official API, and the users behind it are burning about 92 trillion tokens a day. It is the first hard adoption number in the agent race from any lab, and it arrives from the open-model challenger, not from the two companies that built the category.</p>

<h2>What the growth math says</h2>
<p>The headline is the slope, not the level. From about 271,000 daily users at the end of September to 1.54 million on November 4 is about 5.7 times in roughly five weeks, by our arithmetic. The 271,000 figure was the seven-day average as of September 30, just after the desktop version shipped on September 29, according to Bloomberg's coverage, which makes the desktop release the visible inflection point: Harness went live on August 13, spent six weeks as a framework, and took off when ordinary users could download an app. Twelve weeks from launch to 1.54 million daily users is fast for a developer tool, and it is faster still when the count excludes everyone who runs Harness with a third-party API or another model, which DeepSeek does not count at all.</p>

<h2>What 92 trillion tokens a day means</h2>
<p>Divide the two headline numbers and the agent era gets its first public price tag: about 92 trillion tokens a day across 1.54 million daily users works out to about 60 million tokens per user per day, or about 1.1 billion tokens every second. That is the South China Morning Post's framing, and it is the most important number in the disclosure, because it is the first available evidence of how much more compute agents use than chatbots. A chatbot answers a prompt and stops. An agent runs a long task, calls tools, reads files, retries, and keeps going while the user does something else. Each of those steps is tokens, and a user with an agent running all day burns tokens at a rate no chat interface ever approached. DeepSeek has not published the distribution, so the 60 million figure is an average, not a typical user, and a small number of heavy users could be doing most of the burning. But the order of magnitude is the story: agents are a compute demand shock, and this is the first time a lab has put a public number on it.</p>
<h2>The caveats that matter</h2>
<p>Three caveats belong next to the numbers, not buried below them. First, the figures are self-reported by DeepSeek, with no independent audit cited in any of the coverage, and they should be read as the company's claim about its own product. Second, the count is partial by design: it includes only people using Harness through DeepSeek's official API, so anyone connecting a third-party API or running Harness against another model is not counted, which means the true total is higher than 1.54 million, by an unknown amount. Third, the growth window is short and includes a launch event, the desktop release on September 29, so the five-week slope is not a run rate anyone should extrapolate. A number that grows 5.7 times in five weeks after a desktop launch is a launch curve until it proves otherwise, and the proof will be the next disclosure, not this one.</p>
<h2>What a harness is</h2>
<p>A harness is the software infrastructure that turns a large language model into an AI agent that can autonomously execute tasks on behalf of a user, rather than simply responding to prompts. It is the layer that lets a model run code, use external software, keep state across a long task, and call tools in sequence. OpenAI and Anthropic leveraged their early advantage in building harnesses to create Codex and Claude Code, their industry-leading coding products, according to the South China Morning Post. DeepSeek's Harness is the open-source challenger in that same category: the same job, built on open models, with the plugin system as the distribution mechanism instead of a closed app store.</p>
<h2>The operating-system bet</h2>
<p>DeepSeek is not describing Harness as a tool. Cui Tianyi, a former Jane Street engineer who joined the Harness team in March 2026 and now leads DeepSeek's first product division, said on Sunday that the goal is for Harness to act as an operating system for the agent era. He likened it to a smartphone operating system that ships with tools like an alarm clock and a calculator while letting developers integrate alternatives through third-party plugins, much as phone users download alternative apps. The plugin numbers support the analogy so far: about 35,000 third-party plugins have been built, and about 60 percent of active users have built or installed at least one, though their complexity varies. Community examples cited by the South China Morning Post include a plugin that combines tools for reading, highlighting and translating academic papers while letting an agent answer questions about the material, and another that shows developers what information an agent is using and how that changes through a conversation. DeepSeek said it will build a marketplace where developers can publish plugins and users can find them, with a support programme offering token grants, technical discussions and promotional help. No launch date was announced. The company also set up its first product division last month, led by Cui, according to the Chinese outlet The Paper, which is the clearest sign yet that DeepSeek is turning from a research lab that publishes models into a company that sells products.</p>
<h2>The gap no one can fill yet</h2>
<p>The number that would put 1.54 million in context does not exist in public: neither OpenAI nor Anthropic has published daily user counts for Codex or Claude Code. That gap cuts both ways. DeepSeek can claim the fastest-growing agent app, because nobody else has published a number to beat. But it also means nobody can say whether 1.54 million is large or small against the category leaders, only that it grew fast from a standing start. <a href="https://www.byteherald.com/2026/11/a-284b-model-runs-on-64gb-of-ram-at-9.html">Harness is built on DeepSeek's open models, the same family that now runs on a desktop CPU: our report on the modchip build carries the full speed table for the 284 billion parameter flagship</a>. <a href="https://www.byteherald.com/2026/10/small-ais-big-scoreboard-what-4gb-model.html">And the open models behind Harness are the same ones people run themselves: our deep dive on the 4GB tier spent a whole post on a single model, the Bolt E4B</a>. What to watch is the next disclosure: whether the growth holds past the desktop-launch bump, when the plugin marketplace actually opens, and whether OpenAI or Anthropic ever answers with a number of their own. Until one of them does, DeepSeek owns the only public scoreboard in the agent race, and it is winning it by default.</p>
