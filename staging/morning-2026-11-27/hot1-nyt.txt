<p>The New York Times is requiring contributing photographers to avoid Adobe Photoshop 2027, release 28.0.0 and subsequent updates, when working on assignment for The Times. The reason, <a href="https://petapixel.com/2026/11/24/new-york-times-prohibits-photographers-from-using-photoshop-2027/">confirmed by Times spokesperson Graham James to PetaPixel on November 24, 2026</a>, is that certain functions use generative AI in ways that may not be apparent to users and can result in metadata identifying photographs as AI-generated. Adobe's own labeling rules show the risk is real but narrower than a version-wide ban suggests: only qualifying generative AI tools attach the metadata, and the metadata records whether content was wholly generated or modified.</p>

<h2>What Adobe says triggers the label</h2>
<p><a href="https://helpx.adobe.com/creative-cloud/apps/generative-ai/ai-content-labeling-faq.html">Adobe's generative AI content labeling FAQ, last updated August 25, 2026</a>, states the rule plainly. When qualifying generative AI tools are used to create or modify content in Adobe apps, C2PA metadata is automatically attached to the file. The rule applies only to generative AI tools, not to traditional AI-powered features. The metadata cannot be disabled for qualifying content, and Adobe does not automatically add a visible AI label. The attached metadata may include the application used, the generative model used, whether the content was wholly generated with generative AI or modified using generative AI, the date and time of use, and a unique content identifier.</p>
<p>That modified-versus-generated distinction is the detail the version-wide ban skips. A photograph touched by one qualifying generative tool carries metadata saying it was modified using generative AI, which is a different claim from wholly generated. The Times email, as reported, does not name the features it is concerned about. The ban treats the whole release as suspect because a photographer may not know which tool crossed the generative line. <a href="https://www.byteherald.com/2026/10/how-ai-image-generation-actually-works.html">ByteHerald's explainer on how AI image generation works</a> covers the underlying split between tools that synthesize new pixels and tools that only analyze or adjust existing ones, which is the same split Adobe's labeling rule uses.</p>
<h2>The 28.0 feature risk matrix</h2>
<p>Photoshop 28.0 shipped in November 2026. <a href="https://helpx.adobe.com/photoshop/desktop/whats-new/photoshop-on-desktop-release-notes.html">Adobe's release notes, last updated November 10, 2026</a>, list the new features, and <a href="https://helpx.adobe.com/creative-cloud/apps/generative-ai/creative-cloud-generative-ai-features.html">Adobe's generative AI features page, last updated November 24, 2026</a>, classifies which Photoshop tools count as generative AI features. ByteHerald cross-checked the two lists on November 27, 2026. The matrix below separates the 28.0 additions Adobe classifies as generative from the ones it does not.</p>

<p>The matrix shows why the Times chose a version ban over a feature list. Six of the headline 28.0 additions are qualifying generative tools, and two more are AI surfaces whose risk depends on what edit they apply. A photographer doing routine work in 28.0 can reach a generative tool through the AI Assisted Editor without opening a menu that says generative. The ban removes that judgment call from deadline work. It does not follow that every edit in 28.0 writes an AI label: Adobe's rule attaches metadata when a qualifying generative tool creates or modifies content, and traditional adjustments such as cropping and minimal color work are not qualifying generative use.</p>
<h2>Why the metadata matters more than the edit</h2>
<p>C2PA metadata travels with the file and records origin and editing history in a machine-readable form. For a newsroom, the problem is downstream. Platforms that display provenance information decide for themselves whether and how to show it, so a modified-with-generative-AI record can surface to readers in ways the newsroom does not control. The Times has long supported C2PA provenance, and its photo standards already bar adding, removing, or rearranging elements in published photographs. The 28.0 restriction protects that standard from an accidental metadata record, not from a deliberate fake.</p>
<p>PetaPixel reported that photographers can roll back to Photoshop 27.0, but no earlier. That makes the practical choice narrow: stay on 27.x for Times assignments, or keep 28.0 and accept that any qualifying generative edit writes a provenance record into the file that Adobe says cannot be disabled at creation. Adobe had not responded to PetaPixel's request for comment at publication. Until Adobe publishes a per-feature labeling map inside the app, newsrooms that need clean provenance have one reliable control, which is the version pin The Times just imposed.</p>
