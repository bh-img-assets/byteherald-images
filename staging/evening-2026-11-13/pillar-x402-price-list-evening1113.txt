<p>Brave started selling search by the call on November 12, 2026. No account, no API key, no subscription. An agent sends a request, the server answers with HTTP 402 Payment Required and a price, the agent signs a stablecoin payment for that exact amount, and the search runs. The protocol is x402, and Brave is the first major independent search provider to sell on it, a characterization one independent probe used when it read Brave's invoice. We sent unpaid requests to two x402 sellers and read the invoices they returned. This is the price list, the fee math, and the limits, measured on November 14, 2026.</p>

<h2>What x402 is</h2>
<p>HTTP has carried a 402 Payment Required status code since the early days of the web, and almost nothing ever used it. x402 revives it as a payment protocol. A server that wants to charge for an API call answers an unpaid request with a 402 and a machine-readable invoice: the price, the network, the token, the address to pay, and how long the offer lasts. The client signs a payment for that amount and retries the request with the signed payment attached. A facilitator verifies the signature and settles the payment on the blockchain. The signed payment is the credential, so there is no API key to store, rotate, or leak, and no account to create before the first call.</p>
<p>The protocol itself is free. The <a href="https://x402.org">x402 Foundation, which governs the standard under the Linux Foundation</a>, describes it as an open, neutral standard for internet-native payments, with zero protocol fees: the customer and the merchant pay only nominal network fees. Coinbase introduced x402 in May 2025. The foundation's member list stood at 57 organizations as of October 19, 2026, including Coinbase, Cloudflare, Stripe, Google, AWS, PayPal, Visa, Mastercard, and American Express, with the technical steering committee seats held by Coinbase, Cloudflare, and Stripe. Membership is not the same as selling: Visa, Mastercard, and American Express help govern the standard, but none of them sells an x402 endpoint. The companies that actually move the money are the facilitators, the clouds, the wallets, and the sellers, and the table below is the first compiled list of what the sellers charge. We mapped the whole agentic commerce stack in October, five layers from the cart to the card network, with x402 as one row inside it: <a href="https://www.byteherald.com/2026/10/when-your-ai-agent-buys-something-who.html">When Your AI Agent Buys Something, Who Gets Paid?</a> priced the stack, and the prices below price the rail.</p>
<h2>The price list</h2>
<p>Two sellers publish per-call prices on x402 today, and both settle in USDC on the Base blockchain. <a href="https://brave.com/blog/search-api-agentic-payments/">Brave's announcement</a> puts its eight search paths at the same price, and <a href="https://medium.com/@agentsearchhq/x402-python-tutorial-let-your-ai-agent-pay-per-call-for-web-search-f3d77211a350">AgentSearch's own tutorial</a> lists search, extraction, and a combined search-and-read call at three different prices. The facilitator that settles the payment charges its own fee, which is the number that decides whether a micropayment is worth collecting at all.</p>

<h2>We read the invoices</h2>
<p>An unpaid request costs nothing, and the invoice it returns is the most honest document in this market, because the server has to state its terms before it can be paid. We sent one unpaid request to each seller and decoded the payment-required header each returned. No payment was sent in either probe, so the pay-then-retry loop was not completed end to end, and this article does not claim it was.</p>
<p>Brave's invoice, for a web search, arrived as HTTP 402 Payment Required with an empty body, zero bytes. The header decoded to x402 version 2, scheme "exact", network eip155:8453, which is Base, amount 5000 base units of a six-decimal token, which is 0.005 USD, asset 0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913, which is the canonical USDC contract on Base, payee 0xFFa76529d7e733C7671190b374819d8eDA2b9D04, a 300-second expiry, and the transfer method EIP-3009, a signed transfer authorization, so the agent signs but never broadcasts its own transaction. Exactly one payment option was offered: one chain, one token, one price, no menu, no negotiation. Brave's own machine-readable price list, at <a href="https://search.agent.s.brave.app/llms.txt">llms.txt on the same proxy</a>, lists the same eight paths at the same 5000 base units, and its <a href="https://api-dashboard.search.brave.com/documentation/guides/agent-payments">documentation</a> says the 402 is the authoritative price, which our probe confirmed.</p>
<p>AgentSearch's invoice, for a search, decoded to the same shape with different numbers: x402 version 2, scheme "exact", network eip155:8453, amount 8000 base units, which is 0.008 USD, the same USDC contract, payee 0xC49B157887e51c21CB655f39CF65D6a4c2a4C337, a 300-second expiry, and the service name "Web Search API | AgentSearch". The payee address matches the one in AgentSearch's own tutorial, which is a useful check: before trusting a payee, compare it with the published list, and ours matched. Two independent probes of Brave's invoice, published by developers on November 12 and 13, 2026, decoded the same 5000 base units, the same chain, and the same transfer method: <a href="https://dev.to/minia2a/a-search-api-went-x402-native-today-here-is-its-402-byte-for-byte-2lpj">one read the 402 byte for byte on November 12</a>, and <a href="https://dev.to/frankchu/0005-per-search-i-read-braves-402-invoice-for-agents-4073">another read the invoice on November 13</a>, and the first of the two called Brave the first major independent search provider to sell per call on the protocol. The one difference between the two sellers is the body: Brave's 402 body was empty, while AgentSearch's carried 3,775 bytes, so this article does not claim an empty body for AgentSearch.</p>
<h2>The settlement fee is the floor</h2>
<p>The most important number in the table is not a seller's price. It is the facilitator's fee, because it sets the floor below which a micropayment cannot work. Coinbase's CDP facilitator, the most used one, is free for the first 1,000 transactions a month and charges 0.001 USD per transaction beyond that, <a href="https://eco.com/support/en/articles/14839402-x402-protocol-explained">according to Eco.com's reading of the CDP documentation</a>. On Brave's 0.005 USD ticket, that fee is 20 percent of the price. On AgentSearch's 0.008 USD search, it is 12.5 percent. On the 0.007 USD extract, it is 14.3 percent. A seller that charges less than a tenth of a cent per call would hand the entire price, and more, to the facilitator.</p>
<div class="separator" style="clear: both; text-align: center;"><img src="https://raw.githubusercontent.com/bh-img-assets/byteherald-images/main/img/pillar-x402-price-list-evening1113-chart2.png" alt="Bar chart: the facilitator fee of 0.001 USD is 20 percent of Brave's 0.005 USD ticket, 12.5 percent of AgentSearch search at 0.008 USD, and 14.3 percent of AgentSearch extract at 0.007 USD" /></div>
<p>Brave's own price list proves the point, because it publishes the calls it will not sell. Its Answers API is not sold on x402, since it bills per query and per token, which one fixed price cannot express. Autosuggest and Spellcheck are not sold either, and Brave says why in its own documentation: they cost less than the fee a facilitator takes for settling one payment, so they wait on settling many queries together as one payment. The Summarizer is not sold because Brave has deprecated it. A path outside the eight in the table is a 404, never a payable 402, and a payment is checked against the price of the path it is sent to, so a payer cannot name its own price. The rule that falls out of this is simple: x402 works for calls priced above the settlement fee, and the sub-cent calls it was supposed to unlock are exactly the ones that still need batched settlement to exist.</p>
<p>That is also why Brave's gas promise matters and why it should be read carefully. Brave says gas fees for transacting on Base will be covered for a limited time. Neither this article's probes nor the two independent probes published on November 12 and 13 completed a purchase, so nobody outside Brave has verified end to end that the gas is covered, or for how long "a limited time" lasts. The claim is Brave's, and it is recorded here as Brave's.</p>
<h2>Who else sells on x402, and who does not</h2>
<p>Brave and AgentSearch are the two sellers with published per-call prices we could verify from a live invoice. The rest of the market is wider but less transparent. The official documentation lists 15 production facilitators, including Coinbase CDP, PayAI, Corbits, Dexter, Fireblocks, Polygon, Celo, and the Stellar and NEAR facilitators, and Coinbase's CDP facilitator alone reports more than 100 million transactions on Base and Solana. PayAI lists eight mainnets; Circle's facilitator service settles USDC on Arc, Base, and Polygon PoS. By April 2026, five named deployments were running in production: Coinbase's Agent.market directory, Stripe's machine payments, CoinGecko's paid endpoints, Circle Wallets' reference workflow, and the Cloudflare Agents SDK. The x402.org counter, as read in <a href="https://payzum.com/blog/x402-ecosystem-2026/">an October 19, 2026 ecosystem map</a>, showed about 94,000 buyers against 22,000 sellers, which says the buyers arrived before the sellers did.</p>
<p>The comparison that matters most for a buyer is not between two x402 sellers but between x402 and the card rails. OpenAI's ChatGPT Wallet, launched the same week Brave went live on x402, takes the opposite approach: tokenized cards, no commission at launch, and a security check before every purchase, with the agent never seeing the real card number. We covered that launch and the fight over whether stores will let agents buy at all in <a href="https://www.byteherald.com/2026/11/chatgpt-wallet-lets-agents-pay-not.html">ChatGPT Wallet Lets Agents Pay. Not Every Store Agrees</a>. Google's Agent Payments Protocol, known as AP2, has an x402 extension, and the competing protocols named in the trade press are Stripe and OpenAI's Agentic Commerce Protocol and Visa's Trusted Agent Protocol. None of those publishes a per-call price, so this article does not invent one for them. The honest summary is that x402 is the cheapest rail to quote, because its prices are public and per call, and the card rails are the cheapest rail to use, because the buyer already has a card. Which one wins depends on whether the seller wants a price list or a checkout form.</p>
<p>That distinction is also where the October picture fits. The permission question from that stack has not gone away: an agent that can pay still has to be allowed to buy, and the stores that block agents, mapped in <a href="https://www.byteherald.com/2026/10/the-great-agent-lockout-who-blocks-ai.html">our map of who blocks AI agents</a>, do not care which rail the payment arrives on.</p>
<h2>Five tests for the rail</h2>
<p>The rail passes or fails on five tests. First, Brave's promised support for other networks and stablecoins, which would break the current one-chain, one-token shape. Second, batched settlement for sub-cent queries, which is the only way Autosuggest and Spellcheck ever get sold, and which Brave says is coming. Third, whether a second major search provider joins, since one seller is a feature and two sellers are a market. Fourth, whether the facilitator fee falls below 0.001 USD as volume grows, since the fee is the floor and the floor decides which calls can exist. And fifth, whether the 57-member foundation ships a version 3 of the protocol that changes the invoice format, since every client that parses the payment-required header, including ours, depends on the shape staying stable.</p>
