<p>A 100 dollar Claude Max subscription bought about 4,640 dollars worth of Claude Opus 5.5 at API prices in a measurement posted on X on November 20, 2026, a 46.4 times multiple. The same test put Google AI Ultra at 25.8 times on Gemini 4 Neon. But two other independent measurements put Max at 55 times and 72 times, so the honest number is a range, not a single multiple, and the range is the story.</p>

<h2>Why three counts disagree</h2>
<p>The disagreement is not an error. It is the shape of the product. Anthropic does not publish its subscription allowance as a token count. It <a href="https://benchleader.com/coding-plans/claude-max">describes Max as 5 times Pro usage every 5 hours and every week</a>, plus 100 dollars a month in API credits for the Claude Platform. Nobody outside Anthropic knows how many tokens that meter holds, so every measurement has to infer it from usage, and different usage gives different answers.</p>
<p>The three counts used three different methods. Huryn ran benchmark workloads and priced them at API rates. A separate measurement <a href="https://zenn.dev/tottoko_hamu/articles/2026-05-22-000000?locale=en">published on zenn.dev</a> counted 139 real session files from Claude Code over 16 days in May 2026, priced every token at the Opus 4.7 rates of the time, and reached about 5,425 dollars a month, or about 55 times the subscription. <a href="https://benchleader.com/coding-plans/claude-max">BenchLeader</a> estimated the full-use allowance from Real API Pricing data and reached about 7,224 dollars a month on Opus 5.5, or 72 times. Same plan, three methods, three answers: 46.4, 55, and 72. A fourth count points the same way: SemiAnalysis reported on October 5, 2026, that a 200 dollar Claude plan still had 50 percent of its allowance left after consuming 2,485 dollars of Fable 5.1, <a href="https://enjoy.dev/blog/cheapest-claude-opus">as covered on enjoy.dev</a>.</p>
<p>The mix of tokens matters as much as the method. In the zenn.dev count, which ran on Opus 4.7 in May 2026, 52 percent of the Opus cost came from cache reads, which Anthropic then priced at 50 cents per million tokens, against 5 dollars for fresh input and 25 dollars for output. A workload that re-reads a lot of cached context racks up a large API-equivalent bill very cheaply in tokens. A workload heavy on fresh output looks different. And heavier models drain the meter faster: Huryn's own numbers show it, with Max at 46.4 times on Opus 5.5 but only 27.3 times on Fable 5.2, the dearer model at 8 dollars input and 40 dollars output per million tokens.</p>
<p>None of this makes any of the three counts wrong. It makes the single-number claim wrong. At full use, Claude Max is worth somewhere between about 46 and 72 times its price on Opus, and every measurement in that range agrees on the direction: the subscription is worth far more than 100 dollars a month to a heavy user.</p>
<h2>The break-even test</h2>
<p>The multiple only matters if you would otherwise pay API prices, so the useful question is the break-even point. <a href="https://benchleader.com/coding-plans/claude-max">BenchLeader</a> puts it at 313 agent sessions a month on Opus 5.5: past that, Max costs less than the API for the same work. Its comparison of the three Claude tiers, all priced on Opus 5.5 at full use, is Pro at 20 dollars a month worth about 1,200 dollars, or 60 times; Max at 100 dollars worth about 7,224 dollars, or 72 times; and Ultra at 200 dollars worth about 12,426 dollars, or 62 times. Max wins per dollar. Ultra wins on absolute allowance.</p>
<p>There is a second piece of arithmetic that changes the test. Max includes 100 dollars a month in API credits, outside the usage pool. If you use the Anthropic API at all, those credits alone match the subscription price, before the plan allowance is worth anything. Light users still come out ahead on the zenn.dev numbers: Sonnet-only use ran 500 to 1,000 dollars a month at API prices, or 5 to 10 times the subscription. The plan only loses if you barely use it, and an unused allowance is worth zero at any multiple.</p>
<p>The other side of the same question is what researchers actually pay at list prices. OpenAI reported on November 18, 2026, that its median researcher used about 2,400 dollars of tokens a day in October, and the top tenth used about 23,000 dollars a day. We covered that report in <a href="https://www.byteherald.com/2026/11/openais-researchers-now-burn-2400-day.html">OpenAI's Researchers Now Burn $2,400 a Day in AI Tokens</a>. If you are the person paying those list prices, a 100 dollar subscription that covers the same work is not a discount. It is a different price for the same tokens.</p>
<h2>How subscription allowances work</h2>
<p>The gap between the subscription and the API exists because they sell different things. The API sells tokens: <a href="https://enjoy.dev/blog/cheapest-claude-opus">4 dollars per million input tokens and 20 dollars per million output tokens for Opus 5.5, with cache reads at 20 cents and cache writes at 5 dollars</a>. The subscription sells a meter: a usage allowance that resets every 5 hours and every week, sized for an average user. Anthropic prices the meter for the average subscriber, not the heaviest one, so a power user who runs the meter to empty every cycle gets far more than 100 dollars of tokens for 100 dollars. That is the arbitrage, and it only holds while the meter stays generous. Anthropic can tighten it, and it has a separate weekly limit for Fable, its most expensive model, which is the pressure valve. Those list prices are themselves falling fast: model rates dropped sharply through 2026 as labs cut prices to win share, and a multiple measured against today's prices may not hold next quarter. We tracked that slide in <a href="https://www.byteherald.com/2026/10/ai-got-75-cheaper-discounts-are-expiring.html">AI Got 75% Cheaper. The Discounts Are Expiring</a>.</p>
<h2>What the multiple does not mean</h2>
<p>First, it is not cash saved. It is the API price of usage you got for a flat fee, and it only saves you money if you would otherwise have bought that usage at API prices. Second, it assumes full use. The allowance resets, and what you do not use is gone. Third, the meter is a cap, not a guarantee: 5-hour and weekly limits can cut a heavy session short, and Fable has its own weekly limit on top. Fourth, the October rows are stale, and the November rows are one workload on one day. Treat 46 to 72 times as the range the evidence supports for a heavy Opus user, not as a promise, and run your own count before switching: if your monthly API bill is under 100 dollars, the API is cheaper, and if it is over 100 dollars, Max is.</p>
