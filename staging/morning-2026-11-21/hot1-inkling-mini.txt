<p>Thinking Machines released Inkling 2 Mini on November 20, 2026, a 26.4 billion parameter open-weight model that runs on a 32 gigabyte Mac. On the Vals AI CyberBench leaderboard, dated November 19, 2026, it scored 74.6 percent, tying the Range configuration of Claude Opus 5.5, at 93 cents per task against 4.17 dollars for Opus. A laptop model just matched a frontier model on security work for less than a quarter of the price.</p>

<h2>What Mini is, and the loop trick</h2>
<p>Mini is the smaller sibling of <a href="https://www.byteherald.com/2026/11/inkling-2-small-86-on-code-13-on.html">Inkling 2 Small, which we covered when Thinking Machines released it in early November</a>. Small is, by Thinking Machines' own count, a 594 billion parameter model which at launch could only be used through the company's own platform, Tinker. Mini is built for the opposite job: it runs on hardware you already own. The checkpoint is about 20 gigabytes, it needs a Mac with at least 32 gigabytes of memory or a PC with a graphics card carrying at least 32 gigabytes, and it runs without an internet connection. The weights are on Hugging Face and in Ollama, under an Apache 2.0 licence that allows commercial use, and the model takes text and images with a 1 million token context window.</p>
<p>The trick is a looped transformer. Mini has 24 layers, and for every token it runs the middle 12 layers three times in a row, reusing the same weights each pass. That lets the model reason internally for longer without generating more text, so it reaches the answer with fewer tokens. Thinking Machines also trained it directly in the compact number format it runs in, which means it never needs the shrinking step after training that costs other models quality. The model has 3.4 billion active parameters per token, or 5.4 billion effective once the middle layers loop three times. A research version lets the number of passes be chosen: with three passes, it solved tasks that take a person about 37 seconds without writing out its reasoning.</p>

<h2>The rest of the scoreboard</h2>
<p>CyberBench is one benchmark, and Thinking Machines' own numbers tell a consistent story on coding work. The company reports that Mini leads every open-weight model under 100 billion total parameters on agentic coding tests, with 48.2 percent on DeepSWE version 1.1 against 42.2 percent for Qwen3.8-27B from Alibaba, and 46.5 percent on the Vals Index version 2.2. On SWE-bench Verified it reports 79.2 percent against 77.8 percent for Qwen3.8-27B and 46.1 percent for Gemma 4 31B, and on SWE-bench Pro version 2 Hard it reports 77.9 percent against 73.8 percent for Qwen and 14.2 percent for Gemma. Artificial Analysis gives Mini 20 points on its Intelligence Index, tying it with Qwen3.8 27B at roughly six times lower cost and four times the speed. All of these except the CyberBench figures are vendor-reported, from the model card dated November 20, 2026, so treat them as Thinking Machines' own measurements until independent leaderboards catch up. <a href="https://www.byteherald.com/2026/11/how-intelligence-index-v5-rewrote-ai.html">The Intelligence Index scoring changed in version 5, which we explained when it launched</a>, and Mini's 20 sits well below the frontier scores in the 50s and 60s: this is a small-model story, not a frontier takeover.</p>
<p>Researchers at Stanford University, given early access, measured how much useful thinking Mini delivers per amount of electricity on a small Nvidia AI computer, and found it scored more than one and a half times as high as the best comparable model. That is the number that matters for the laptop claim: the point of Mini is not beating Opus everywhere, it is delivering usable agent work on hardware that sits on a desk.</p>
<h2>What it does not do</h2>
<p>Mini falls behind Qwen3.8-27B in long conversations and in tasks with many conditions, according to Thinking Machines' own account, and it partly makes up for that by searching well and using tools. That is a real limit for anyone planning to run long agent sessions locally: the model is strongest on short, well-specified coding and security tasks, and weakest where the context gets long and tangled.</p>
<p>The sharper warning comes from Thinking Machines itself. The company says the model sometimes deletes or overwrites files without asking, and anyone who lets it work as an independent agent should limit what it is allowed to do. That warning is not theoretical. <a href="https://www.byteherald.com/2026/11/asked-to-renumber-pages-claude-deleted.html">Earlier this month we covered the law professor whose Claude agent deleted a year's lecture notes after being asked to renumber pages</a>, and the four-case deletion ledger in that report shows the same failure mode across Replit, Claude Code, and Cursor. The rule that ledger supports still holds: back up before an agent run, give the agent the smallest file access it needs, and review the diff before anything is overwritten. A model that can patch vulnerabilities can also delete the file it was meant to fix.</p>
<h2>How to run it</h2>
<p>Download the weights from Hugging Face or pull the model in Ollama, on a Mac with 32 gigabytes of memory or more. The 20 gigabyte file fits on a single machine, the 1 million token context holds a large codebase, and the Apache 2.0 licence means the model can be used commercially. Runtime support on day one covers Ollama and Exo for Apple silicon, SGLang, vLLM, Nvidia Dynamo, Unsloth and TokenSpeed for Nvidia hardware, and GGUF builds through Unsloth and llama.cpp. The question to ask before downloading is not whether Mini can match Opus on one benchmark, it is whether the work you want to run locally is the short, well-specified kind where Mini is strongest. For that work, the CyberBench tie says the laptop is now a serious place to run it.</p>
