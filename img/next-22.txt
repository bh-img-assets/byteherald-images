<p>ByteHerald's finding: Postman announced it was reverting the forced agent-plugin install on November 5, 2026, eleven days after the report. The revert then split in two. The plugin repository removed the hook self-approval the same day, but the build npm served by default still contained it on November 9. The announcement and the shipped artifact told different stories for at least four days.</p><p>The underlying incident is documented in Postman's own support tracker. The first is installation: an upgrade path for existing desktop users wrote plugin entries into two other applications' configuration without an opt-in in those applications. The second is trust: the installer contained a function that approved Postman's own Codex startup hook, writing the trust record the host application reserves for the user's decision. The plugin repository's October 21 commit message explains the engineering motive, keeping hook approval stable across plugin updates. Motive does not settle consent.</p><p>The revert has the same two layers, and only one closed cleanly. Postman's November 5 staff comment conceded the messaging misjudgment and promised a redesign with the right level of control. PR 149, merged that day, removed the self-approval and dropped the Codex hook. Version 0.7.0 carried the fix that evening. Hours later the pull request was reverted and 0.7.1 shipped; the fix was re-applied on November 6 as 0.7.2, which was never published. As of November 9, the default npm install still resolved to 0.7.1. Analysis: a revert that does not reach the default artifact is a statement of intent, not a completed fix, and already-installed plugins are a separate cleanup question the revert alone does not answer.</p><h2>Methodology and limits</h2><p>Methodology: ByteHerald ordered the dated records from the issue, the staff comment, and the November 9 registry report, and counted eleven days from the October 25 filing to the November 5 revert statement. It does not establish the current registry state after November 9, or whether the redesigned experience has shipped. It establishes the sequence from silent install to announced revert to unpublished fix, which is the sequence a user deciding whether to trust the tool needs.</p><p>By ByteHerald Staff.
