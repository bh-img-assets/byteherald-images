Craft-fast, Craft-ultrafast and MCP access were roadmap items in the launch material, not shipped features. That distinction matters because image models are often judged by launch claims while buyers need the working contract: resolution, formats, latency, price and edit behavior.</p>

<h2>How the two-stage design differs</h2>
<p>A conventional diffusion model starts from noise and removes noise in steps while text guidance steers the result. Craft adds an explicit planning stage first. The plan covers which elements appear, where they sit, their relative scale, the visual hierarchy and the text that must appear. The rendering stage then produces the image from that plan. Canva says the model was trained on human-designed templates such as posters, presentations, menus and infographics, which matches the design use case better than a photo-first dataset.</p>
<p>Analysis: planning should help most where failure is structural. A poster can have a beautiful background and still fail if the headline collides with a product image or the price is unreadable. A plan gives the renderer a layout to follow and gives the user a better chance to edit one element without regenerating the whole composition. It does not remove the need to check text, hands, logos and factual details in the final image.</p>
<h2>Cost and limits</h2>
<p>The launch record establishes access and output size, but a buyer still needs per-image price, credit use, latency under load, commercial-use terms and failure rates on text-heavy prompts. Canva's claim of more than 30 aspect ratios should be tested against the exact sizes a workflow needs, because design production depends on export dimensions and safe margins. The promised faster variants cannot be priced until Canva publishes rates and dates.</p>
<p>Analysis: the citable shift is architectural. Image generation is moving from prompt-to-picture toward prompt-to-layout-to-picture. The evidence that would strengthen Canva's claim is a public test set of design tasks scored for text accuracy, hierarchy and edit stability, with cost and latency reported beside quality.</p>
<p>Analysis: the planning stage also changes how failures should be measured. A photo model can be scored on realism, but a design model must be scored on whether the headline is legible, the hierarchy survives export, the brand color stays fixed, and an edit to one element leaves the rest intact. Canva's template training points toward those tasks, yet the launch record does not publish a task-level error rate. A practical evaluation would run the same briefs through Craft and rival models, then score text accuracy, layout collisions, edit stability, time to finished file and total credit cost. That test would show whether planning produces production value or only a better first draft.</p><p>Until that evidence exists, the safest production use is supervised design drafting. A human still checks text, brand compliance and export size before publication.</p><p>That check protects brand and legal accuracy.</p><p>By ByteHerald Staff.
