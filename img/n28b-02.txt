<p>On price, DeepSeek's API pricing page, checked November 13, 2026, lists deepseek-flash at $0.003 per 1M cache-hit input tokens, $0.15 per 1M cache-miss input tokens, and $0.60 per 1M output tokens off-peak, with peak rates exactly double. A cache hit therefore costs 50 times less than a cache miss, which means prompt reuse, not the headline rate, sets most of a real bill.</p>
<p>One more pattern is worth noting for buyers comparing across the full table. The gap structure is therefore consistent: the model is strongest exactly where tasks run long and tools do the work, and weakest where a single hard reasoning step decides the outcome.</p><h2>Methodology and limits</h2>
<p>Methodology: we transcribed the 11 published benchmark rows and computed gaps, gains, the median gain, and the four-benchmark coding average arithmetically. Limits: these are DeepSeek's own reported numbers, run under DeepSeek's chosen harnesses, including the Claude Code harness for Terminal-Bench 4.0 and the Mini-SWE-V2 harness for DeepSWE v1.1. No independent replication exists yet, sample sizes and variance are not published, and small gaps such as the 1.0 point Chartography difference should be read as ties. The evidence does not establish how the model performs on any specific production workload.</p>
<h2>Analysis</h2>
<p>Analysis: the win pattern fits a model tuned for agent loops, where finishing tasks matters more than peak reasoning depth. Teams routing long-horizon automation work get the strongest case for trying it, while teams buying raw reasoning still face a double-digit HLE gap. The price structure strengthens the automation case, since agent loops reuse long system prompts and tool definitions that bill at the cache-hit rate.</p>
