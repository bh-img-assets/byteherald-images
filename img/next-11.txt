<h2>Methodology</h2>
<p>ByteHerald used three dated documents: Meta launch announcement dated October 12, 2026, Meta Muse Wonder Model Card released October 12, 2026, and Artificial Analysis Muse Wonder article published October 12, 2026. We extracted max reasoning effort figures where the source states max effort, copied no source table wording, and recomputed differences and ratios. Where the extracted text gave no Wonder component value, the ledger records the gap rather than estimating. Token pricing is recorded as $4 per million input tokens, $0.20 per million cached input tokens, and $20 per million output tokens for Wonder, with Full not priced per token (Artificial Analysis, October 12, 2026).</p>
<h2>Analysis: gains and cost</h2>
<p>Analysis: the gain is concentrated in agentic and coding rows. Full improves over Spark 1.3 on all ten index evaluations in the Artificial Analysis record, including Terminal-Bench 4.0 from 33% to 57% and GDPval-AA v2.1 by 176 Elo to 1857 (Artificial Analysis, October 12, 2026). Coding Agents Index scores are 68 for Full and 63 for Wonder against 54 for Spark 1.3 (Artificial Analysis, October 12, 2026). Meta describes Active Memory as carrying relevant details across conversations and Active Focus as continuing toward a goal, trying other approaches, and checking in before important steps (Meta, October 12, 2026). This ledger does not test those descriptions; it shows where the independent component gains appear.</p>
<p>Analysis: output efficiency does not produce task savings for the API model. Both Wonder models use about 54k output tokens per task against 60k for Spark 1.3, yet Wonder uses 7.69M input tokens and input is $3.43, or 76%, of its $4.52 task cost (Artificial Analysis, October 12, 2026). Full uses 6.44M input tokens, but no per-token price means no comparable task cost can be computed from these documents. List price alone therefore understates the API model task cost in this record, and composite score alone overstates what an API buyer can access.</p>
<h2>Limits</h2>
<p>This evidence does not establish performance outside the named evaluations. Full leads CritPt and GDP.pdf at 33% each with nearest competitors at 31% to 32%, and its GDPval-AA v2.1 result is within confidence intervals of Claude Opus 5.5 at 1866 Elo and Claude Sonnet 5.5 at 1838 Elo (Artificial Analysis, October 12, 2026). Hallucination rates are 23% for Full and 27% for Wonder in the same record. The model card states Wonder results used max reasoning effort against GPT-6 Astra, Claude Fable 5.1, and Claude Opus 5.5 at max effort (Meta Muse Wonder Model Card, October 12, 2026). Meta run task scores, training data, parameter counts, weight plans, and rollout dates beyond subscribers first are not established by these extracted documents and are not carried forward as findings.</p>
