<h2>Methodology and limits</h2>
<p>Terminal-Bench 4.1 keeps the same 66 tasks as version 4.0 and hardens the verifiers, according to the Terminal-Bench 4.1 release material dated November 9, 2026. Scores are resolution rates with 95 percent confidence intervals of roughly three points. That interval matters: Claude Code, Antigravity and Codex sit within overlapping ranges, so the board does not separate them cleanly on capability. Cost separates them more clearly, because run cost is published per entry.</p>
<p>Three limits apply. First, the benchmark tests an agent plus a model, not a subscription tier. Second, Copilot and Cursor can route to different models, so a tool score is really a combination score. Third, Cursor has no entry among the listed combinations we read, so this scorecard cannot place Cursor. We report that absence rather than estimating a score.</p>
<h2>What the data says</h2>
<p>Analysis: the November board rewards routing and cheap completion more than raw model prestige. Copilot Fusion leads by 5.4 points over the tied Claude Code entries. Below that lead, the practical spread is economic. Antigravity with Gemini 4 Carbon solves 213 tasks at $6.38 per solved task. Codex with GPT-6.2 Astra solves 205 at $6.87. Codex with GPT-6.2 Sol solves 203 at $1.72, which makes it the cost outlier even though its score is lower.</p>
<p>The Claude Code rows carry the clearest warning against reading score alone. Opus 5.5 and Fable 5.2 solve the same number of tasks, 217, but Fable's run cost is about 3.5 times Opus by our division of $16,492.76 by $4,718.65. A buyer who only reads the percentage would miss that difference. A buyer who only reads price would miss that Copilot Fusion solves 18 more tasks than the Claude Code entries.</p>
<p>What this scorecard does not establish is which assistant is best for a specific codebase, language, or review workflow. Terminal-Bench measures terminal task completion under a fixed harness. It does not measure code review quality, repository navigation over weeks, or how often a tool breaks a build after the benchmark ends. The citable finding is narrower: on the November 2026 official board, the cheapest solved task and the highest score belong to different tools.</p>
