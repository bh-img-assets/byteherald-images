<p>ByteHerald's finding: turning off ChatGPT's iCloud access and revoking the credential that grants it are two different actions in two different places. OpenAI's own help pages state that disconnecting an iCloud connection in ChatGPT does not revoke its password at Apple. A user who disconnects and stops there leaves a live Apple app-specific password in place.</p><p>OpenAI announced the iCloud Mail and iCloud Calendar plugins on October 27, 2026, for all ChatGPT plans on web, desktop, and iOS. The Mail plugin can search and read messages, manage messages and drafts, send email, and look up contacts. The Calendar plugin can read, create, and update events and look up contacts. Neither plugin reaches Gmail, Outlook, or other non-iCloud accounts shown inside Apple's Mail app.</p><h2>The credential lifecycle ledger</h2><p>ByteHerald compiled the ledger below from OpenAI's connection guidance and Apple's app-specific password rules. Mail takes an iCloud Mail address. Calendar takes the primary Apple Account email, which can be a different address. OpenAI's reconnect guidance adds that reconnecting one connection does not update the other. A user who fixes Mail after a password change has not fixed Calendar.</p><p>Second, the exit path has a gap. Disconnecting in ChatGPT stops future access through that connection. It does not revoke the password at Apple, and it does not delete existing conversations or saved memories. Apple provides the actual revocation controls: remove a single password or revoke all of them at account.apple.com. Until one of those actions happens, the password remains valid.</p><p>Third, the blast radius is bounded but real. Apple allows up to 25 active app-specific passwords. Using a separate password for Mail and Calendar, which OpenAI's setup implies, occupies 2 of those 25 slots, or 8 percent by ByteHerald arithmetic. That separation is worth the slots: revoking the Mail password signs out Mail only, leaving Calendar untouched. Changing the main Apple Account password is the blunt instrument, because Apple revokes every app-specific password automatically.</p><h2>Methodology and limits</h2><p>Methodology: ByteHerald extracted each rule from the named primary page and ordered the rows by lifecycle stage, from connection to revocation. The 8 percent figure is ByteHerald arithmetic on Apple's stated ceiling of 25. Analysis: the ledger shows where control sits at each step. It does not establish how OpenAI stores the password after connection, how long mail content remains in any given conversation, or whether workspace administrators have disabled the plugins for a particular account. OpenAI notes that app permissions change when ChatGPT asks before using access; they do not grant new access.</p><p>The practical conclusion is narrow. Connect each plugin with its own labeled password, and treat disconnecting as step one of two. The credential is only retired when Apple shows it removed.</p><p>By ByteHerald Staff.
